# Autonomy Contract

KCOS separates autonomy from unrestricted authority.

## Autonomous without routine human intervention
- ingest configured live data
- update market state continuously
- perform full synchronized decision cycles at least every six seconds
- maintain trend/regime/correlation/lead-lag state
- retrieve bounded relevant context
- run Kronos and independent model components
- detect surprises and formulate falsifiable research hypotheses
- create multiple strategy variants
- run research metrics and promotion checks
- rank active strategies for capital
- build order intents
- veto/clip risk deterministically
- place eligible paper/live orders through configured execution venues
- reconcile and audit
- detect strategy/model drift
- demote or retire degraded strategies

## Owner exception events
- broker/exchange KYC or legal agreements
- MFA/OAuth/session steps a provider requires from the account owner
- expired/revoked credentials
- granting new asset/market permissions
- changing immutable risk ceilings
- enabling transfer/withdrawal authority
- emergency-stop/resume decisions when operator intervention is desired

## Self-improvement boundary
KCOS may create new strategy/model/research artifacts, but generated artifacts do not receive production authority merely because an AI produced them. They pass the same fixed evidence and deployment gates as human-authored artifacts.
