## Evidence requirement before meaningful live capital
The package deliberately does not mark any strategy as proven by default. The research worker only promotes strategies when its metrics satisfy fixed gates. Those metrics must be generated by actual backtests, walk-forward runs, paper trades and canary trades rather than manually fabricated values.
